# BIO2105 - Regression Analysis

## Project Description

This project performs correlation and simple linear regression analysis using the built-in R datasets `trees` and `women`.

The analysis explores the relationship between tree girth and timber volume, as well as the relationship between height and weight. It includes data visualization, Pearson correlation, regression modeling, hypothesis testing, confidence and prediction intervals, ANOVA, and regression diagnostics.

## Tools Used

- R
- RStudio
- R Markdown

## Project Files

- `BIO2105_Regression_Analysis.R` – Contains the R code used for the analysis.
- `BIO2105_Regression_Analysis.Rmd` – Contains the R Markdown source, code, explanations, and results.
- `BIO2105_Regression_Analysis.html` – Contains the rendered HTML report.
- `README.md` – Provides an overview of the project.

## How to Run

1. Open `BIO2105_Regression_Analysis.R` in RStudio to run the R script.
2. Open `BIO2105_Regression_Analysis.Rmd` in RStudio.
3. Click the **Knit** button to generate the HTML report.

## Datasets

The project uses the built-in R datasets `trees` and `women`. No external datasets are required.
